### API (уже работает после миграции)

```
GET    /announcements
GET    /announcements/:id
POST   /announcements
PATCH  /announcements/:id
PUT    /announcements/:id
DELETE /announcements/:id
```

**Тело POST/PATCH (пример):**
```json
{
  "title": "Заголовок (необязательно)",
  "message": "Текст объявления",
  "type": "urgent",
  "expiresAt": "2026-07-09T18:00:00.000Z",
  "isActive": true,
  "createdBy": 2
}
```

- `type`: `"urgent"` — срочное (баннер в кабинете) | `"persistent"` — долгосрочное (блок «Актуально»)
- `expiresAt`: `null` — без срока; иначе скрывается после даты
- `isActive`: `false` — выключено вручную
