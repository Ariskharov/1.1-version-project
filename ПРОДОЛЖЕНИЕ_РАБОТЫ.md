#### API (работает после миграции)

```
GET    /announcements
GET    /announcements/:id
POST   /announcements
PATCH  /announcements/:id
PUT    /announcements/:id
DELETE /announcements/:id
```

**Тело POST/PATCH:**
```json
{
  "title": "Заголовок (необязательно)",
  "message": "Текст объявления",
  "type": "urgent",
  "expiresAt": "2026-07-09T18:00:00.000Z",
  "isActive": true,
  "createdBy": 2
}
```

- `type`: `"urgent"` — срочное (баннер в кабинете) | `"persistent"` — долгосрочное (блок «Актуально»)
- `expiresAt`: `null` — без срока
- `isActive`: `false` — выключено вручную

#### Шаг 2. UI в админке
**Файлы:** `src/all_pages/admin/admin.js`, `src/all_pages/admin/admin.scss`

**Куда вставить в JSX:** сразу после `</header>` блока `admin-hero` (~строка 574), **перед** `<div className="admin__top">`. Там логично вся ширина страницы — объявления не смешиваются с журналом смен.

**Секция:** `<section className="admin-announcements" aria-labelledby="admin-announcements-title">`

**Состояние в компоненте:**
```js
const [announcements, setAnnouncements] = useState([]);
const [annForm, setAnnForm] = useState({ title: '', message: '', type: 'urgent', expiresAt: '', isActive: true });
const [editingAnnId, setEditingAnnId] = useState(null);
```
Загрузка при монтировании: `fetchAnnouncements()` → `setAnnouncements`. `createdBy` при создании — `currentUser.id` из контекста.

**Форма создания / редактирования:**
| Поле | Элемент | Поведение |
|------|---------|-----------|
| Заголовок | `<input>` | необязательно, max ~200 символов |
| Текст | `<textarea>` | обязательно |
| Тип | `<select>` или 2 radio | `urgent` / `persistent`, подписи из `ANNOUNCEMENT_TYPES` |
| Дата окончания | `<input type="datetime-local">` | пусто = `expiresAt: null` |
| +24 часа | кнопка | ставит `expiresAt` = сейчас + 24ч |
| Вкл/выкл | checkbox / toggle | `isActive` |
| Сохранить | кнопка | `createAnnouncement` или `updateAnnouncement` |
| Отмена | кнопка | сброс формы, `editingAnnId = null` |

**Список объявлений (под формой):**
- Каждая строка: заголовок/текст, тип, срок (`formatExpiryLabel`), статус активно/выкл
- Кнопки: **Редактировать** (заполняет форму), **Вкл/Выкл** (`updateAnnouncement({ isActive })`), **Удалить** (confirm + `deleteAnnouncement`)
- Показывать и неактивные/просроченные — админ должен их видеть; в кабинете фильтр уже в утилите

**Импорт:**
```js
import {
  ANNOUNCEMENT_TYPES, fetchAnnouncements, createAnnouncement,
  updateAnnouncement, deleteAnnouncement, formatExpiryLabel,
} from '../../utils/announcements';
```
**Тосты:** `showToast` из `CustomContext` — уже используется в админке.

**Стили (`admin.scss`):** блок `.admin-announcements` в духе `.admin-hero` / `.admin__filters` — те же `--adm-*` переменные, карточка с формой сверху и таблицей/списком снизу.

**Опционально:** вынести в `src/components/announcements/AdminAnnouncementsPanel.js` и подключить одной строкой в `admin.js`.

#### Шаг 3. Блоки в личном кабинете
**Файлы:** `src/all_pages/cabinet/cabinet.js`, `src/all_pages/cabinet/cabinet.scss`

**Куда вставить в JSX — два разных места:**

1. **Срочные (`urgent`)** — сразу **после** `</nav>` блока `cabinet-quick-actions` (~строка 527), **перед** `status-section`. Баннер на всю ширину, сразу бросается в глаза.
2. **Долгосрочные (`persistent`)** — **после** `status-section` (~строка 563), **перед** `cabinet-insights`. Отдельный информационный блок «Актуально», не путается со срочным.

**Состояние:**
```js
const [announcements, setAnnouncements] = useState([]);
useEffect(() => {
  fetchAnnouncements()
    .then(setAnnouncements)
    .catch(() => {}); // тихо, кабинет работает без объявлений
}, []);
const urgentNews = filterActiveAnnouncements(announcements, 'urgent');
const bulletinNews = filterActiveAnnouncements(announcements, 'persistent');
```

**Срочный баннер** (если `urgentNews.length > 0`):
```jsx
<section className="cabinet-urgent-news" role="region" aria-live="polite" aria-label="Срочные объявления">
  {urgentNews.map(a => (
    <article key={a.id} className="cabinet-urgent-news__item">
      {a.title && <strong>{a.title}</strong>}
      <p>{a.message}</p>
      {a.expiresAt && <small>До {formatExpiryLabel(a.expiresAt)}</small>}
    </article>
  ))}
</section>
```

**Долгосрочный блок** (если `bulletinNews.length > 0`):
```jsx
<section className="cabinet-bulletin" role="region" aria-labelledby="cabinet-bulletin-title">
  <h2 id="cabinet-bulletin-title">Актуально</h2>
  <ul>
    {bulletinNews.map(a => (
      <li key={a.id}>
        {a.title && <strong>{a.title}: </strong>}{a.message}
      </li>
    ))}
  </ul>
</section>
```

**Импорт:** те же функции из `src/utils/announcements.js`.

**Стили (`cabinet.scss`):**
- `.cabinet-urgent-news` — заметный, но в палитре кабинета (`--cab-*`), не ломает шапку
- `.cabinet-bulletin` — спокойная карточка, как `.status-card` / `.cabinet-insight`

**Проверка глазами:** админ создаёт срочное → сотрудник видит баннер под быстрыми ссылками; долгосрочное → блок «Актуально» над инсайтами; с истёкшим `expiresAt` или `isActive: false` — ничего не показывается.
