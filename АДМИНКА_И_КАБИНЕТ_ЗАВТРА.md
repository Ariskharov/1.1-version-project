## Админка (`admin.js` + `admin.scss`)

### Куда вставить
Сразу **после** блока `admin-hero`, **перед** `admin__top` (~строка 574 в `src/all_pages/admin/admin.js`).

### Что сделать
Секция **«Объявления для сотрудников»** — форма сверху, список снизу.

**Форма:**
- Заголовок (необязательно)
- Текст (обязательно)
- Тип: срочное (`urgent`) / долгосрочное (`persistent`)
- Дата окончания (опционально)
- Кнопка «+24 часа»
- Вкл/выкл (`isActive`)
- Сохранить / Отмена

**Список:**
- Показать все объявления (включая выключенные и просроченные)
- Кнопки: редактировать, удалить, переключить активность

**Технически:**
- Импорт из `src/utils/announcements.js`
- `showToast` при успехе/ошибке (уже есть в админке)
- `createdBy` = `currentUser.id` при создании
- Стили: класс `.admin-announcements`, переменные `--adm-*`

## Личный кабинет (`cabinet.js` + `cabinet.scss`)

### Куда вставить — два разных места

| Тип | Место в JSX | Класс |
|-----|-------------|-------|
| **Срочные** (`urgent`) | После `cabinet-quick-actions`, перед `status-section` (~строка 527) | `.cabinet-urgent-news` |
| **Долгосрочные** (`persistent`) | После `status-section`, перед `cabinet-insights` (~строка 563) | `.cabinet-bulletin` |

### Что сделать

**Загрузка:**
```js
useEffect(() => {
  fetchAnnouncements().then(setAnnouncements).catch(() => {});
}, []);
const urgentNews = filterActiveAnnouncements(announcements, 'urgent');
const bulletinNews = filterActiveAnnouncements(announcements, 'persistent');
```

**Срочные** — баннер на всю ширину под быстрыми ссылками:
- `role="region"`, `aria-live="polite"`
- Заголовок + текст + дата окончания (если есть)

**Долгосрочные** — блок «Актуально»:
- `role="region"`, `aria-labelledby`
- Список новостей без срочного оформления

**Стили:** `--cab-*`, не ломать шапку и статус смены.

## Проверка после работы

1. Админка → создать **срочное** объявление → в кабинете баннер под быстрыми ссылками
2. Админка → создать **долгосрочное** → в кабинете блок «Актуально» над инсайтами
3. Выключить или поставить прошедшую дату → в кабинете ничего не показывается
4. `npm run build` — без ошибок
5. Коммит: `Объявления: API, админка и показ в кабинете`
