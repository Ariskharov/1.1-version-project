## Готовый API (не менять без нужды)

| Что | Значение |
|-----|----------|
| POST | `http://localhost:8080/upload` |
| Поле файла | `file` (FormData) |
| Ответ | `{ "path": "/utilse/имя.jpg" }` |
| DELETE | `http://localhost:8080/upload` body `{ "fileName": "имя.jpg" }` |
| Папка на диске | `backend/uploads/` |
| URL картинки | `/utilse/...` (да, опечатка utilse — так задумано) |

Пример:

```js
const fd = new FormData();
fd.append('file', file); // имя поля обязательно file
const res = await fetch('http://localhost:8080/upload', { method: 'POST', body: fd });
const { path } = await res.json(); // "/utilse/xxx.jpg"
```

### Как подключить (пропсы)

```jsx
<PhotoUploadSlot
  inputId="..."
  variant="card" // card | avatar | banner
  previewUrl={path}           // после upload
  onFileChange={async (e) => {
    const file = e.target.files?.[0];
    if (!file) return;
    // upload → set path
  }}
  onRemove={async () => {
    // DELETE + очистить path
  }}
/>
```

Пока `onFileChange` не передан — слот с бейджем «Скоро», логики нет.
